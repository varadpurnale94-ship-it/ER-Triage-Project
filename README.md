# ER Triage and Patient Priority Manager using C++

## Project Overview
The ER Triage and Patient Priority Manager is a C++ based project designed to manage patients in a hospital emergency room.

The system prioritizes patients according to their emergency condition and severity level, helping medical staff identify critical patients who need immediate attention.

## Objectives
- Manage emergency patient records.
- Assign priority levels based on patient conditions.
- Identify critical patients.
- Improve patient management and organization.
- Demonstrate the use of C++ programming concepts.

## Technologies Used
- Programming Language: C++
- IDE: Visual Studio Code
- Concepts: Structures, Arrays, Conditional Statements, Functions and Sorting.

## Features
- Patient registration.
- Patient information management.
- Emergency priority assignment.
- Patient priority management.
- Display patient records.
